Complete Workflow — How to Actually Benefit

You built a radar, not a money printer. This guide is how you turn Telegram pings into real edge — without drowning in noise or blowing up your account.

1. Mindset — rent momentum, don't marry tokens

You're not investing. You're renting a move from insiders, narratives, or early liquidity — and leaving before they take the car back. LAB holders learned this at -97%. CASHCAT winners sold into Jul 8–11 hype.

Realistic expectation: 20 alerts/week, 1–2 worth trading, maybe 1 big winner/month if you filter well. That's enough to make the system worth it.

4. The 5-minute process (every alert)

1. READ alert — ELITE / WATCH / X / VOL? 2. OPEN DexScreener link — liquidity depth? spread? 3. OPEN Bubblemaps — CLUSTERS view (not individual %) → cluster > 40%? scalp only or SKIP → cluster < 25%? better odds 4. CHECK narrative — fresh (Robinhood new chain) or dead? 5. SIZE — 1–3% portfolio max 6. SET stop — -15% to -20% on memes 7. PLAN exit — take 50% at +50%, rest on Bubblemaps warning

Skip if: fake Solana clone, no liquidity, unlock in 7 days, ZachXBT investigation live.

5. Daily routine (15 min total)

Morning (5 min)

  • Skim overnight Telegram — anything ELITE or X from ataberk/vladytenev?
  • systemctl --user status crypto-watchers — both active?

On alert (5 min)

  • Run the 5-minute process above
  • Trade or add to watchlist — don't FOMO every ping

Evening (5 min)

  • Log trades (see journal below)
  • Coinglass quick check on any open perp positions

7. Long vs short on Binance futures

Go long
  • ELITE/WATCH + fresh narrative
  • No Bubblemaps warning yet
  • No team → CEX flow (Lookonchain)
  • OI rising, funding not extreme
Go short / exit
  • Bubblemaps "ugly" post
  • Team wallets → Bitget/Gate/Binance
  • Vol/mcap > 0.5 on scanner
  • -30% from ATH, no bounce 4h

Avoid shorting concentrated-supply tokens (LAB) — insiders squeeze shorts.

8. Simple trade journal (learn faster)

One line per trade in Notes or a spreadsheet:

Date | Token | Alert source (X/ELITE/VOL) | Entry $ | Size % | Bubblemaps cluster % | Exit $ | Result | Lesson

After 20 trades you'll see: X alerts from ataberk vs random ELITE junk — adjust config accordingly.

9. How to crush it — without burning out

  1. Let the system run 24/7 — systemd does this. You don't scroll X manually.
  2. Trade fewer, better — 2–4 trades/week max from alerts, not every Telegram ping.
  3. Always Bubblemaps — the 30-second step that separates ELITE from trap.
  4. Take profit in tiers — +50% sell half. Memes don't respect your target.
  5. Exit on investigator posts — bubblemaps/lookonchain > your hope.
  6. Specialize chains — you're set up for Robinhood/BSC/SOL. Own that niche.
  7. Review weekly — which alert type made money? Tune config.yaml accounts.
The formula

Telegram finds it → DexScreener sizes it → Bubblemaps validates it → small position → tiered exit → journal → repeat.
